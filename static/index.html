Open your Claude folder

Pick the .claude folder in your home directory:

  • Linux / macOS~/.claude
  • WindowsC:\Users\<you>\.claude

It's a hidden folder. In the picker press Cmd+Shift+. on macOS or Ctrl+H on Linux to show it.

This browser can't change local files, so the folder opens read-only: you can browse and read transcripts, but not delete. Use Chrome or Edge for everything, or run serve.py.
